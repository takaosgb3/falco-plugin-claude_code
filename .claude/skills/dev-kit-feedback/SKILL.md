# Dev-Kit フィードバック収集

$ARGUMENTS について、開発済みプラグインとdev-kitテンプレートの差分を分析し、改善提案を行います。

## 引数
- **plugin-path**: 分析対象のプラグインディレクトリパス

## 実行手順

### 1. プラグインコード読み込み
対象ディレクトリの以下のファイルを読み込む:
- cmd/plugin-sdk/plugin.go
- pkg/parser/parser.go, config.go, regex_simple.go
- Makefile, go.mod
- rules/*.yaml

### 2. テンプレートとの差分検出
.claude/templates/plugin/ 配下の対応テンプレートと比較し、差分を特定。

### 3. 差分の分類
- **テンプレート改善**: テンプレート自体を改善すべき変更
- **スキル改善**: スキルの手順・ガイドを改善すべき変更
- **新規パターン**: PROBLEM_PATTERNS.md に追加すべき新知見
- **ドメイン固有**: そのプラグイン特有の変更（テンプレートに反映不要）

### 4. 改善提案レポート出力
差分分析結果を以下の形式で報告:
- 改善カテゴリ別の一覧
- 優先度（High/Medium/Low）
- 具体的な改善案

### 5. PROBLEM_PATTERNS.md 候補の提示
新規パターンがあれば、P コード形式で追加候補を提示。

## 成功基準
| ID | 基準 |
|----|------|
| FB-001 | 対象プラグインの全コードが読み込まれている |
| FB-002 | テンプレートとの差分が分類されている |
| FB-003 | 改善提案レポートが出力されている |
