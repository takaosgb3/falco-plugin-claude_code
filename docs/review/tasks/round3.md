### 対応方針
- 本書の Pコード「概要」は dev-kit 要件 v2 §C2 が原典（T2-5 で `PROBLEM_PATTERNS.md` に集約予定）
- 「要件 v3 §18.4 マッピング」列は claude-code 要件 v3 で同番号がどの要件節に対応するかを示すが、**意味解釈が一致しない番号がある**
- これは「Pコード番号体系を別々に運用している」結果であり、本書側で**注記による明示**が必要。**修正対象 (R3-01)**。

## B. 要件 v3 §18.4 列の正確性（dev-kit 解釈と独立）
要件 v3 §18.4 の本書転記が要件 v3 本文と完全一致するか再確認:
- P001 要件 v3: `§7.4, §21.1, §21.2 B-003/B-004, AC-013` → 本書「§7.4, §21.1, §21.2 B-003/B-004」 → **AC-013 が漏れている**。**修正対象 (R3-02)**
- P005 要件 v3: `§13 R-002, §18.3, §29` → 本書「§13 R-002」 → **§18.3, §29 が漏れている**。**修正対象 (R3-03)**

その他の P コードは Round 1 で修正済み。

## C. SC コード整合
- §7.7 では SC-001〜SC-053 の範囲表のみで、飛び番（009, 014-019, 025-029, 034-039, 044-049）が意図的か不明。**修正対象 (R3-07)**: 「飛び番は将来拡張用」を注記。
- §5.7 T4-4（plugin-scaffold スキル更新）の完了基準に SC-001〜SC-008 への言及がない。**修正対象 (R3-05)**。
- §5.8 T4-5（plugin-parser スキル更新）の完了基準に SC-010〜SC-013 への言及がない。**修正対象 (R3-06)**。

## D. テンプレート変数 ${PLUGIN_DESCRIPTION}
§7.5 で `${PLUGIN_DESCRIPTION} | v2 新規 | T4-1（PluginEvent 非依存化と同時）` と記載。要件 v2 §E7 で「T4-1: Info() の Description を動的化」とあるが、本書 §5.4 T4-1 の変更内容に Info() への言及なし。**修正対象 (R3-04)**: T4-1 の変更内容に追加。

## E. 受入完了判定
§8.6 の 10 項目に E4（Go 1.22+, Falco 0.43+, plugin-sdk-go 0.7.4+）への明示的なチェックがない。要件 v2 §E4 として書かれている互換性要件は受入の前提として確認すべき。**修正対象 (R3-08)**。
