## B. 誤り疑い・章間整合
- B1: §1.4 依存関係図で「T4-1 (PluginEvent 非依存化) ─ T1-1 への再改修」の表現が、矢印の方向（依存）と意味（再改修）で混乱する。注釈で意図を明示。**修正対象**。
- B2: §4.5 T3-3 の先行タスクは `T3-1, T3-2` のみ。release.yml.tmpl は OS 自動検出 (T1-2) と build-release (T3-1) の両方が必要。**T1-2 を追加**するのが正確。**修正対象**。
- B3: §4.7 T3-5 に「Pコード関連」行がない。MaxFieldLength 配線変更は P020 (truncate vs 全文返却) と関連するため追加。**修正対象**（軽微）。
- B4: §3.3 T2-1 の先行タスクが「T1-1（A3-2 が T1-1 に統合済みのため依存関係に注意）」と書かれているが、T2-1 自身（regex_simple.go.tmpl の truncate 化）は T1-1 の parser 接続を実装上は必要としない。注釈の意図は「URL デコード集約は T1-1 で済」だが、それを「先行タスク」欄に書くと混乱。**修正対象**（軽微）。
- B5: §1.5.6 受入テスト表に ET-* (拡張受入テスト) への参照がない。§8.2.2 に ET-1〜ET-6 が定義されているので「拡張受入テストは §8.2.2 参照」と注記。**修正対象**（軽微）。
- B6: §6.12 Step 5 完了確認の PR コミット数「8〜9 コミット」は誤り。実装タスクは T5-1, T5-2, (T5-3 スキップ), T5-4 (+T5-5 同梱可), T5-6, T5-7, T5-8, T5-9 → 7〜8 コミット。**修正対象**（軽微）。
- B7: §7.5 `${PLUGIN_NAME_UPPER}` が「T4-4（scaffold で生成）」のみ。実際は plugin_rules.yaml.tmpl 等のテンプレート内で使用される既存変数なので「全タスク（テンプレート内で使用）」に近い。**修正対象**（軽微）。
